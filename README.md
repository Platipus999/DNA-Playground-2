# DNA Playground

A beginner Python project for exploring basic DNA sequence statistics through an interactive web interface.

## Features

- Calculate DNA sequence length
- Calculate GC and AT content
- Visualize nucleotide composition
- Display a color-coded DNA sequence
- Validate input sequences

## Built with

- Python
- Streamlit
- HTML and CSS

## Run locally

1. Install Python.
2. Install dependencies:

   `python -m pip install -r requirements.txt`

3. Launch the app:

   `python -m streamlit run labapp.py`

## Purpose

A small learning project exploring Python programming, interactive interfaces, and software deployment.
